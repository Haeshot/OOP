# Лабораторная работа 4: правило трёх для класса Matrix

## Назначение
Класс `Matrix` — матрица целых чисел произвольной размерности.
Данная версия демонстрирует управление динамической памятью через
**правило трёх**: конструктор копирования, оператор присваивания,
деструктор.

## Возможности класса
- Три конструктора: по умолчанию (0×0), единичная матрица (size×size),
  прямоугольная (rows×cols), заполненная нулями.
- **Конструктор копирования** — глубокое копирование: новая память,
  поэлементная копия значений.
- **Оператор присваивания** `operator=` — освобождает старую память,
  затем копирует новые данные. Защита от самоприсваивания.
  Возвращает `Matrix&` для цепочек.
- **Деструктор** — освобождает память в обратном порядке: строки,
  затем массив указателей.
- `get` / `set` с проверкой индексов (`std::out_of_range`).
- `fillRandom`, `inputFromKeyboard`, `print`, `sum`, `getRows`, `getCols`.

## Почему деструктор не вызывается дважды для одной памяти
Правило трёх гарантирует, что каждый объект владеет **своей** памятью:
1. **Конструктор копирования** создаёт новую память и копирует данные
   поэлементно — оригинал и копия указывают на разные участки.
2. **Оператор присваивания** сначала освобождает старую память объекта,
   затем выделяет новую под копию. Оригинал не трогается.
3. **Защита от самоприсваивания** (`if (this == &other) return *this;`)
   предотвращает освобождение памяти, которая используется как источник.
4. **Деструктор** освобождает только «свою» память — выделенную
   конструктором данного объекта.

Без этих гарантий при копировании оба объекта указывали бы на один
участок памяти, и при разрушении вызывался бы `delete[]` дважды —
undefined behavior.

## Пустая матрица (0×0)
- Конструктор с нулевой размерностью память не выделяет.
- Конструктор копирования от пустой матрицы создаёт пустую.
- `operator=` от пустой матрицы освобождает старую память и обнуляет поля.
- Деструктор безопасен: `freeMemory()` проверяет `data_ != nullptr`.

## Рефакторинг работы с памятью
Работа с памятью вынесена в три приватных метода:
- `allocate(rows, cols)` — выделяет память, ставит размеры.
- `copyFrom(other)` — приводит `*this` к копии `other`.
- `freeMemory()` — освобождает память, обнуляет поля.

Это убирает дублирование:
- `new int*[...]` — только в `allocate`;
- двойной цикл копирования — только в `copyFrom`;
- `delete[]` — только в `freeMemory`.
