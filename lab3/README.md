# Лабораторная работа: класс Matrix

## Назначение класса
Класс `Matrix` представляет матрицу целых чисел произвольной размерности.
Поля класса закрыты (`private`), доступ к данным — только через методы.

## Возможности
- Конструктор по умолчанию: матрица 0x0, память не выделяется.
- Конструктор с одним параметром: единичная квадратная матрица size x size.
- Конструктор с двумя параметрами: матрица rows x cols, заполненная нулями.
- Деструктор освобождает память в обратном порядке.
- `get` / `set` — доступ к элементам с проверкой индексов.
- `inputFromKeyboard` — заполнение с клавиатуры.
- `fillRandom` — заполнение случайными числами от 0 до 99.
- `print` — построчный вывод.
- `sum` — сумма всех элементов.
- `getRows` / `getCols` — размеры матрицы.

## Исключения
- При отрицательных размерах выбрасывается `std::invalid_argument`.
- При выходе за границы в `get` / `set` выбрасывается `std::out_of_range`.

## Пустая матрица
Если размерность равна 0, память не выделяется.
Деструктор корректно работает с `data_ == nullptr`.
